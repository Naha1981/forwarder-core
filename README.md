# Forwarder Core (working name)
Standalone freight-forwarding prototype. Not part of CargoIQ. Synthetic data only.
Rebuilt from public descriptions of forwarding systems (organisation, quote, booking, shipment, container, milestone, job costing). It is not a copy of any vendor product and uses no vendor code or data.
Run: `python3 -m http.server` then open http://localhost:8000. Test: `npm test`.
